# Primary reference register

Checked: **2 October 2026**. Recheck before a regulatory decision or a version-sensitive implementation. Guides in this repository are authored preparation exercises, not reproductions of a standard or evidence of conformity.

| Source | Status / how to use it |
| --- | --- |
| [NIST SP 800-82 Rev. 3](https://csrc.nist.gov/pubs/sp/800/82/r3/final) | Final OT security guidance, September 2023; the page notes a Rev. 4 initial public draft in September 2026. A draft does not replace the final revision |
| [NIST CSF 2.0](https://csrc.nist.gov/pubs/cswp/29/the-nist-cybersecurity-framework-csf-20/final) | Final framework, February 2024; useful outcomes vocabulary, not a product certification |
| [NIS2 directive](https://www.boe.es/buscar/doc.php?id=DOUE-L-2022-81963) | EU text; check national implementation, sector, size and exceptions separately |
| [METI SCS](https://www.meti.go.jp/policy/netsecurity/scs.html) | Official scheme page, including March 2026 construction policy; IT scope must not be conflated with OT |
| [JSON Schema 2020-12 validation](https://json-schema.org/draft/2020-12/json-schema-validation) | Public schemas use this dialect; enable timestamp format validation explicitly |

For each use, record the exact source/version, checked date, relevant scope, interpretation, reviewer and unresolved questions. A link's existence does not confirm that a requirement applies to a particular company or that a control has been implemented.
