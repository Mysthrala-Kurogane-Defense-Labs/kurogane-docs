# Kurogane Docs

Public documentation topics for Kurogane Hub, MKDL's private commercial OT cybersecurity and industrial monitoring platform for industrial SMEs and micro-SMEs.

**Status: preliminary.** The glossary contains definitions; most topic pages currently repeat a short scope statement. They are outlines for future documentation, not deployment instructions, detailed architecture specifications or evidence of implemented controls.

## Start here

- **Services and contact:** [MKDL website](https://mkdl.jp/).
- **Public ecosystem and repository map:** [Kurogane](https://github.com/Mysthrala-Kurogane-Defense-Labs/kurogane).
- **Definitions:** [glossary](docs/glossary.md).
- **Integration examples:** [Satellite SDK](https://github.com/Mysthrala-Kurogane-Defense-Labs/kurogane-satellite-sdk), with preliminary event contracts and a dry-run example.
- **Synthetic demonstrations:** [Kurogane Labs](https://github.com/Mysthrala-Kurogane-Defense-Labs/kurogane-labs).
