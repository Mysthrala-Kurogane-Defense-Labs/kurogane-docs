# Kurogane Docs

Kurogane Docs provides public technical documentation for the public technical ecosystem around Kurogane Hub.

Kurogane Hub is MKDL's commercial OT cybersecurity and industrial monitoring platform for industrial SMEs and micro-SMEs. It is designed to support operational visibility, data sovereignty, and regulatory alignment work without claiming automatic compliance.

## Audience

Industrial SMEs, micro-SMEs, OT engineers, IT teams, Elixir and Phoenix reviewers, PLC and SCADA stakeholders, investors, partners, and security researchers evaluating the public integration surface.

## Topics

- On-premise, hybrid, and satellite deployment models.
- Data sovereignty and operational risk.
- Plant modeling and digital twin concepts.
- High-level NIS2 and METI alignment.
- SME onboarding and integration vocabulary.
